# 🛡️ 청년체크 (YouthCheck)

> **"광고 없이, 직장인도 받을 수 있는 알짜 청년 정책만 3초 만에 체크"**  
> 복잡한 중위소득 기준표와 상업성 블로그 광고에 지친 2030 청년·직장인을 위한 실전 정책 큐레이션 & 커리어 플랫폼

---

## 📖 1. 프로젝트 기획 배경 및 의도 (Why YouthCheck?)

대한민국 청년을 위한 정부·지자체 지원 정책은 매년 수백 가지가 쏟아져 나오지만, 정작 바쁜 2030 청년들은 다음과 같은 문제로 혜택을 놓치고 있습니다:

1. **상업용 낚시성 블로그와 광고의 피로감**  
   - 구글이나 포털에서 정책을 검색하면 정작 공식 신청 페이지는 찾기 어렵고, 대출 광고나 클릭 유도용 블로그 링크로 도배되어 있습니다.
2. **난해한 행정 기준 ("기준 중위소득 150% 이하"?)**  
   - 일반 직장인이나 사회초년생은 자신의 건강보험료나 가구원 합산 중위소득을 계산하기 어려워 자신이 대상자임에도 포기하곤 합니다.
3. **복잡한 행정명 중심의 정보 전달**  
   - 어려운 고시 명칭 뒤에 숨겨진 **"누가 받을 수 있는지"**와 **"얼마나 주는지"**를 파악하는 데 너무 많은 시간이 소모됩니다.

**청년체크(YouthCheck)**는 이러한 불편함을 해소하기 위해, **광고 제로(0%) · 100% 공공기관 정식 다이렉트 링크 · 직관적인 연봉/나이 기준 실시간 대조**를 원칙으로 탄생했습니다.

## ⚡ 2. 핵심 강조 포인트 (Key Highlights)

### ① 행정명 대신 '핵심 자격(누가?) + 혜택(얼마나?)' 직관 노출
- 읽을 필요 없는 긴 서론 문단을 카드 전면에서 과감히 제거했습니다.
- **[🎯 대상: (누가?)]**를 최상단 굵은 헤드라인으로 노출하여 1초 만에 내가 대상자인지 판별합니다.
- **[🏛️ 정책: 공식명]**과 **[💰 혜택: (얼마나?)]**를 균형감 있는 폰트 크기로 나란히 배치해 받을 수 있는 금전적 지원을 즉각 확인합니다.
- `중소기업 재직 필수`, `무주택 세대주 필수` 등 결정적 탈락 요인은 **🚨 빨간색 강조 뱃지**로 처리해 스크롤을 내리면서도 1초 만에 필터링할 수 있습니다.

### ② 노이즈 제로(Zero-Noise) & 100% 공공기관 다이렉트 아웃링크
- 영리 목적의 배너 광고와 제휴 링크를 일절 배제했습니다.
- 카드 클릭 시 서민금융진흥원, 국토교통부(주택도시기금), 국세청 홈택스, 복지로, K-패스 등 **공식 신청 페이지로 다이렉트 연결**됩니다.

### ③ 투 트랙(Two-Track) 메인 탐색 UX
- **🎯 내 조건으로 3초 만에 찾기 (Button A)**:
  - 3단계 미니 온보딩(나이 → 연봉 → 고용형태)을 통해 내게 딱 맞는 정책 개수를 실시간으로 계산하고 맞춤 리스트로 자동 이동합니다.
- **👀 모든 정책 먼저 둘러보기 (Button B)**:
  - 온보딩 없이 전체 정책 리스트로 스무스 스크롤 다운하여 자유롭게 탐색할 수 있습니다.

### ④ 모바일 퍼스트(Mobile-First) 아코디언 인터랙션
- 출퇴근길 스마트폰 한 손 조작에 최적화된 카드 UI.
- 복잡한 제출 서류 목록과 자격 체크리스트는 별도 페이지 이동 없이 카드 내 **[자격 & 서류 ▾]** 버튼으로 부드럽게 펼쳐집니다.

### ⑤ 3대 대분류 정보 구조 (Top-Level 3 Pillars)
1. **🏛️ 청년 정책 (Policies)**: 맞춤 필터링, 상시/마감 캘린더 타임라인 뷰, 로컬스토리지 북마크 저장.
2. **💡 청년꿀팁 (Tips & Labor)**:
   - **5대 중분류 카테고리 필터** 지원 (`이력서` · `이직&취직` · `재테크` · `부업` · `노동관련법규`)
   - **이력서**: NCS 직무능력은행 200% 활용법 피처드 가이드, 경력기술서 STAR 작성 템플릿 (원클릭 클립보드 복사 지원)
   - **이직&취직**: 마지막 출근 전 챙겨야 할 퇴사 서류 5가지 체크리스트, 국민내일배움카드 훈련장려금 월 최대 20만 원 수령 팁, 퇴직금 계산 & 실업급여 수급 요건
   - **재테크**: 급전 시 청약통장 납입액 90% 저금리 담보대출 팁, 중소기업 소득세 감면 5년 치 경정청구 환급법, K-패스 vs 기후동행카드 비교 선택법
   - **부업**: 재택 AI 데이터 라벨링 입문, 크몽 전자책 & 노션 템플릿 무자본 판매법, 당근 스토리 숏폼 동네 맛집 영상 부업 총정리, 직장인 N잡러 5월 종합소득세 및 건보료 기준, 프리랜서 3.3% 환급금 5년 치 홈택스 무료 조회법
   - **노동관련법규**: 3.3% 프리랜서 알바생 퇴직금 & 실질적 근로자성 판정 기준, 근로계약서 필수 5대 체크포인트 & 수습 감액 기준, 주 15시간 이상 주휴수당 계산 및 소급 청구법
3. **📢 실시간 소식 (News & Notice)**: 부처별 청년 정책 최신 고시, 접수 일정 및 가상자산(코인) 과세 개정 쟁점 실시간 브리핑.

## 🛠️ 3. 기술 스택 (Tech Stack)

| 구분 | 기술 스택 | 설명 |
| :--- | :--- | :--- |
| **Framework** | **Next.js 16 (App Router)** | 서버 컴포넌트, 정적 사전 렌더링(Static Generation), Turbopack 번들링 |
| **UI Library** | **React 19** | 최신 React 동시성 및 모던 훅 기반 컴포넌트 설계 |
| **Language** | **TypeScript 5** | 엄격한 타입 안정성 및 명확한 데이터 모델링 (`Policy`, `ContentItem`) |
| **Styling** | **Tailwind CSS v4** | 유틸리티 퍼스트 CSS, 반응형 모바일 최적화, 다크모드 대응 |
| **Icons** | **Lucide-react** | 직관적이고 깔끔한 모던 벡터 아이콘 셋 |
| **State** | **Zustand** | `zustand/middleware`를 통한 필터 및 북마크 LocalStorage 영구 동기화 |
| **Typography** | **Pretendard & Geist** | 가독성이 뛰어난 한국어 폰트 스택 적용 |

## 🎯 5. 수록 대표 정책 및 가이드 예시

### 🏛️ 청년 정책 대표 항목
- **청년도약계좌** (`FINANCE`): 만 19~34세 + 연봉 7,500만 원 이하 직장인 대상, 5년간 최대 5,000만 원 목돈 마련 + 정부기여금 최대 6% 추가 및 비과세.
- **청년 버팀목 전세자금대출** (`HOUSING`): 만 19~34세 무주택 세대주 대상, 연 1.8%~2.7% 초저금리로 전세보증금 최대 2억 원 대출.
- **중소기업 취업청년 소득세 감면** (`TAX`): 중소기업 재직 만 15~34세 청년 근로자 대상, 5년간 소득세 90% 즉시 감면 (연 최대 200만 원).
- **경기도 청년 복지포인트** (`CAREER`): 경기 소재 중소기업 재직 청년 근로자 대상, 연간 최대 120만 원 복지포인트 분기별 지급.
- **청년 국가기술자격시험 응시료 지원** (`CAREER`): 만 34세 이하 청년 누구나 소득 무관, Q-Net 국가기술자격(기사·산업기사·기능사) 응시료 50% 즉시 감면 (연 3회 한도).
- **K-패스 청년 할인** (`FINANCE`): 만 19~34세 전국 청년 대상, 전국 지하철·버스 이용 시 30% 현금 캐시백 환급.

### 💡 실전 취업 & 이력서 꿀팁
- **NCS 직무능력은행 완벽 활용법**: 흩어진 과거 직장 경력, 국가기술자격증, 국비교육 이수 내역을 고용보험 연동 국가 인증 계좌로 모아 이력서에 제출하는 실전 팁.
- **경력기술서 STAR 기법 템플릿**: Situation-Task-Action-Result 기반 성과 수치화 작성법 및 원클릭 복사 가능한 실전 서식 제공.

## 🚀 6. 로컬 실행 방법 (Getting Started)

### Prerequisites
- Node.js `v18.17` 이상 (권장: Node.js LTS v20+)
- npm `v9+`

### Installation & Run
```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 실행 (Turbopack)
npm run dev

# 3. 브라우저 접속
# http://localhost:3000
```

### Production Build & Verification
```bash
# 타입 검사 및 정적 번들 빌드
npm run build

# 프로덕션 서버 실행
npm start
```
